DLLM(Diffusion Large Language Model)은 확산 방식으로 텍스트를 생성하는 대규모 언어 모델이다. LLM과 별개의 범주라기보다는, 주로 자기회귀 방식을 쓰는 LLM과 생성 방식이 다른 모델이다.

---

## DLLM이란?

DLLM은 이미지 생성에서 쓰이던 확산 모델(Diffusion Model)의 원리를 텍스트에 적용한 모델이다. Stable Diffusion, DALL-E 2 같은 모델에서 쓰이는 아이디어를 텍스트용으로 바꾼 것이다.

확산 모델은 데이터에 점진적으로 노이즈를 추가하고 이를 제거하면서 데이터의 분포를 학습한다. DLLM은 이걸 텍스트에 적용해서 텍스트를 왜곡한 후 복원하는 과정을 통해 언어의 구조와 의미를 배운다. 텍스트 전체의 문맥을 동시에 볼 수 있다는 게 특징이다.

## 기존 LLM의 작동 방식

기존 대규모 언어 모델은 주로 두 가지 학습 방식으로 작동한다.

### 자기회귀 방식 (Autoregressive)

GPT가 대표적이다. 이전 단어들을 기반으로 다음 단어를 순차적으로 예측한다. "나는 학교에"가 주어지면 "갔다"를 예측하는 식이다.

### 마스크 언어 모델링 (Masked Language Modeling)

BERT가 사용하는 방식이다. 문장 내 일부 단어를 가리고 이를 예측한다. "나는 [MASK]에 갔다"에서 [MASK]가 "학교"임을 맞추는 식이다.

GPT와 BERT 모두 트랜스포머로 문맥을 처리하지만, 생성 방식과 학습 목표가 다르다. GPT 계열은 앞선 토큰을 바탕으로 생성하고, BERT는 가려진 토큰의 앞뒤 문맥을 함께 본다. 순차 생성 여부만으로 긴 문맥 처리 능력을 판단할 수는 없다.

---

## DLLM의 작동 방식

DLLM은 확산 모델의 원리를 텍스트에 적용하며 두 가지 핵심 과정으로 작동한다.

### 전진 과정 (Forward Process)

원본 텍스트에 점진적으로 노이즈를 추가해 왜곡한다.

```
원본: "인공지능은 미래 기술의 핵심입니다"
  ↓
약한 노이즈: "인공지능은 [NOISE] 기술의 핵심입니다"
  ↓
중간 노이즈: "[NOISE] [NOISE] 기술의 [NOISE]입니다"
  ↓
강한 노이즈: "[NOISE] [NOISE] [NOISE] [NOISE] [NOISE]"
```

### 역과정 (Reverse Process)

학습에서는 왜곡된 텍스트로부터 원래 토큰을 예측한다. 생성할 때는 노이즈나 마스크로 시작해, 주어진 조건에 맞는 새로운 텍스트를 점진적으로 만든다.

자기회귀 생성과 달리 DLLM은 한 단계에서 여러 위치의 토큰을 병렬로 갱신할 수 있다. 다만 여러 복원 단계가 필요하므로 실제 속도는 단계 수와 구현에 따라 달라진다. 자기회귀 트랜스포머도 학습할 때는 여러 위치의 예측을 병렬로 계산한다.

## 기존 LLM과 DLLM의 차이점

### 학습 방식

자기회귀 모델은 다음 토큰을, BERT 같은 마스크 모델은 가려진 토큰을 예측하며 학습한다. 여기서 토큰은 단어 전체일 수도, 단어의 일부일 수도 있다.

DLLM은 텍스트 전체에 노이즈 추가/제거 방식을 사용한다. 병렬 처리로 전체 구조를 고려하며 점진적으로 복원하는 방식으로 학습한다.

### 문맥 처리

긴 문맥을 얼마나 잘 활용하는지는 모델 구조, 문맥 창 크기, 학습 데이터 등에 영향을 받는다.

양방향 문맥을 사용하는 DLLM은 복원 중인 위치의 앞뒤 정보를 함께 고려할 수 있다. 다만 이것만으로 자기회귀 모델보다 긴 문맥에 강하다고 단정할 수는 없다.

### 생성 방식

자기회귀 생성 모델은 Top-k Sampling, Nucleus Sampling, Beam Search 등의 기법으로 토큰 단위 순차 생성을 한다. BERT 자체는 같은 방식의 생성 모델이 아니다.

DLLM은 초기 노이즈에서 시작해 병렬로 노이즈를 제거하며 전체 텍스트를 만든다. Step 수를 조절해 생성 품질과 속도를 맞출 수 있다.

### 종합 비교

| 측면 | 자기회귀 LLM | DLLM |
|:---|:---|:---|
| 학습 목표 | 다음 토큰 예측 | 노이즈·마스크 복원 |
| 생성 처리 | 토큰 단위 순차 생성 | 여러 위치를 병렬 갱신하며 반복 복원 |
| 문맥 방향 | 생성 위치의 앞선 토큰 | 복원 위치의 앞뒤 문맥 활용 가능 |
| 생성 속도 | 출력 길이와 구현에 의존 | 출력 길이·복원 단계 수·구현에 의존 |
| 성숙도 | 매우 성숙 | 초기 연구 단계 |
| 적용 사례 | GPT, LLaMA 등 | LLaDA 등 |

## 결론

DLLM은 확산 모델의 원리를 텍스트에 적용한 접근이다. 여러 위치를 함께 갱신하고 앞뒤 문맥을 활용하는 생성 방식의 가능성 때문에 연구가 이어지고 있다. 2025년 2월 공개된 [LLaDA 연구](https://arxiv.org/abs/2502.09992)는 8B 규모에서도 이 접근을 시험했다.

아직 초기 단계여서 넘어야 할 산이 많다. 학습 효율성, 대규모 벤치마크 검증, 실제 응용 사례, 기존 LLM과의 결합, 컴퓨팅 비용 같은 과제들이 남아있다.

## Jenkins 서버에서 취약점이 발견되었다?

하루는 클라우드 서비스의 `CWPP(Cloud Workload Protection Platform)`에서 Jenkins 서버가 떠있는 인스턴스에 심각한 취약점이 발견되었다고 알람이 왔습니다.

![2023-10-14-image1](2023-10-14-image1.png)
_CWPP 보안 취약점 알람_

> CWPP는 클라우드 워크로드를 보호하기 위한 보안 플랫폼으로, 취약점 스캔, 위협 탐지, 컴플라이언스 모니터링 등의 기능을 제공합니다.
{: .prompt-info }

원인을 파악해보니 `Jenkins Email Extension Plugin` 해당 플러그인에서 취약점이 발견되었다는 것입니다.

### 취약점 상세 정보

**이슈 번호:** [CVE-2023-25765](https://www.jenkins.io/security/advisory/2023-02-15/#SECURITY-2939)

**취약점 유형:** Script Security sandbox bypass vulnerability

**영향 받는 버전:** Email Extension Plugin 2.93 이하

**심각도:** Critical

> 이 취약점은 공격자가 Jenkins의 Script Security 샌드박스를 우회하여 임의의 코드를 실행할 수 있게 하는 심각한 보안 문제입니다.
{: .prompt-danger }

## 해결 방법

해당 플러그인의 2.93버전 이하에서 발견되는 이슈였습니다. 간단하게 버전을 2.93.1 이상으로 업그레이드하면 이슈가 해결될 것입니다.

따라서 Jenkins 버전을 업그레이드하기로 결정했습니다.

### Jenkins 업그레이드
```bash
# CentOS 기반
sudo rpm --import https://pkg.jenkins.io/redhat/jenkins.io-2023.key

yum update jenkins -y
```

### JDK 버전 확인 및 업그레이드

만약 Jenkins 버전을 업데이트했는데 Jenkins가 실행이 안된다면 `JDK 버전`을 확인해봐야 합니다.

> Jenkins v2.375.1-1.1 버전부터는 **JDK 11** 이상이 필요합니다.
{: .prompt-warning }

**JDK 11 설치:**
```bash
curl -L https://corretto.aws/downloads/latest/amazon-corretto-11-x64-linux-jdk.rpm -o jdk11.rpm

yum install jdk11.rpm
```

### 업그레이드 후 확인

Jenkins 재시작 후 다음을 확인합니다:

1. Jenkins 웹 UI 접속 확인
2. Email Extension Plugin 버전 확인 (Jenkins 관리 → 플러그인 관리)
3. 기존 Job들의 정상 동작 확인
4. CWPP에서 취약점 재스캔 및 해결 확인

## 정리

Jenkins 보안 취약점 해결 프로세스:

### 취약점 정보

| 항목 | 내용 |
|:---|:---|
| **CVE 번호** | CVE-2023-25765 |
| **영향 플러그인** | Email Extension Plugin |
| **취약 버전** | 2.93 이하 |
| **패치 버전** | 2.93.1 이상 |
| **심각도** | Critical |
| **취약점 유형** | Script Security sandbox bypass |

### 해결 단계

1. **취약점 발견**: CWPP 알람으로 취약점 인지
2. **원인 파악**: Email Extension Plugin 버전 확인
3. **Jenkins 업그레이드**: 최신 버전으로 업데이트
4. **JDK 호환성 확인**: 필요 시 JDK 11+ 설치
5. **검증**: 업그레이드 후 정상 동작 및 취약점 해소 확인

### 주요 포인트

**Jenkins 버전 관리:**
- 정기적인 보안 업데이트 확인 필수
- [Jenkins Security Advisory](https://www.jenkins.io/security/advisories/) 모니터링
- 자동화된 취약점 스캔 도구 활용 (CWPP 등)

**업그레이드 시 주의사항:**
- Jenkins 버전과 JDK 버전 호환성 확인
- 플러그인 의존성 확인
- 백업 필수 (설정 파일, Job 설정 등)
- 테스트 환경에서 먼저 검증

**보안 모범 사례:**
- 최소 권한 원칙 적용
- 플러그인은 필요한 것만 설치
- 정기적인 보안 패치 적용
- 네트워크 격리 (내부망 운영)
